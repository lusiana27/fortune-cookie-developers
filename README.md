One original fortune-cookie line for a software developer, at most 120 characters.
`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The line warns against the hasty shortcut every developer knows: the hour it saves
today is paid back tomorrow, when that same shortcut has become the legacy code
its own author must inherit. A fortune with a twist — you are your own future reader.

## Run it

```sh
python3 main.py
```

## Entry

> Beware the shortcut: today it saves an hour, tomorrow it becomes the legacy you inherit.
